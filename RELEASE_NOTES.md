# UISI Document Constructor 1.2.1

- Added an optional bilingual template mode for Ukrainian and English document layouts.
- Create linked English fields directly from their Ukrainian originals while editing a Word template.
- Support both translator-entered pairs and same-value pairs for dates, identifiers, agreement numbers, and other shared content.
- Added a guided language setup screen that groups Ukrainian originals, English translations, and shared fields.
- Added portable `.uisi-translation` work packages that can be transferred to another computer, resumed, and converted into a final DOCX.
- Keep English translation fields empty in the author's document and expose them only in the translator workflow.
- Automatically copy Ukrainian values into linked same-value fields without asking the translator to enter them again.
- Preserve translation pair identifiers and language settings when templates are saved, exported, or imported.
- Allow translation mode to be enabled or disabled for existing templates with a clear in-app notification.
- Allow Ukrainian source values to be selected and copied with Ctrl+C from the translation window while keeping them read-only.
- Improved bilingual dialogs, field lists, scrolling, button sizing, and window focus behavior.
